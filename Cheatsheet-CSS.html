🎨 CSS Cheatsheet Visual

Ejemplos interactivos con editor en vivo — modifica el código de la derecha y los cambios se reflejan al instante.

1 Selectores y Especificidad

Selectores modernos :hover, :has(), :is()

:hover — Pasa el mouse
:not(.x) :has(span) :is(h1, h2)
CSS 
.s1-card:hover {
  background: #f06;
  transform: scale(1.08);
}
Decisión: :has() para estilos del padre según hijos. :is() para agrupar sin aumentar especificidad. Preferir clases sobre IDs.

2 Box Model

content → padding → border → margin

Content
CSS 
.s2-inner {
  padding: 12px;
  border: 3px solid #1a5fd0;
  margin: 4px;
}
Tip: Siempre box-sizing: border-box en el reset. Así width incluye padding y borde.

3 Colores y Fondos

Degradados, OKLCH, colores modernos

linear-gradient(135deg, #f06, #4af)
radial-gradient
CSS 
.s3-gradient {
  background: linear-gradient(135deg, #f06, #4af);
  border-radius: 8px;
}
Moderno: oklch(70% 0.2 150) para colores perceptuales uniformes. Mejor que HSL para gradientes suaves.

4 Tipografía Moderna

clamp(), text-wrap: balance, ellipsis

Texto fluido — redimensiona
Título largo sin palabras viudas
Texto muy largo que se corta con puntos suspensivos
CSS 
.s4-fluid {
  font-size: clamp(1rem, 3vw, 1.6rem);
  letter-spacing: -.02em;
}
.s4-ellipsis {
  text-overflow: ellipsis;
  white-space: nowrap;
  overflow: hidden;
}
Decisión: clamp() para tipografía responsive sin media queries. text-wrap: balance solo en titulares (no en párrafos).

8 Bordes y Sombras

border-radius, box-shadow, filter: drop-shadow

shadow
ring
pill

CSS

  box-shadow: 0 2px 8px rgb(0 0 0 / .1);

Tip: box-shadow para sombras de caja. filter: drop-shadow() para sombras que siguen bordes con transparencia.

9 Transiciones

Pasa el mouse — modifica la curva o duración

ease
bounce
color shift
CSS 
.s9-card {
  transition:
    transform .2s ease,
    box-shadow .2s ease;
}
.s9-card:hover {
  transform: scale(1.08);
}
Rendimiento: Transicionar opacity y transform. Evitar transition: all y propiedades como width/height.

10 Animaciones

@keyframes — pasa el mouse para pausar

CSS 
@keyframes anim-bounce {
  from { transform: translateY(0); }
  to   { transform: translateY(-14px); }
}
.s10-bounce {
  animation: anim-bounce .8s ease infinite alternate;
}
Accesibilidad: Usar @media (prefers-reduced-motion: reduce) { animation: none; }.

11 Transformaciones

Pasa el mouse — scale, rotate, translate, skew

scale
rotate
translate
skew
CSS 
.s11-scale:hover {
  transform: scale(1.2);
}
Decisión: Para centrar verticalmente: position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%);.

12 Responsive

clamp(), @media, container queries, dvh

clamp(180px, 70%, 400px)
Redimensiona la ventana — se ajusta solo
CSS 
.s12-fluid {
  width: clamp(180px, 70%, 400px);
  border-radius: 8px;
}
Decisión: @media para layout global. @container para componentes. clamp() para tamaños fluidos. 100dvh para altura real en móviles.

13 Efectos UI Modernos

backdrop-filter, clip-path, glassmorphism

✨ Glassmorphism
clip-path polygon
CSS 
.s13-glass {
  backdrop-filter: blur(12px);
  background: rgb(255 255 255 / .25);
  border-radius: 12px;
}
Decisión: backdrop-filter para glassmorphism. clip-path para formas decorativas. mix-blend-mode: difference para UI adaptable al fondo.

14 Variables CSS

Custom properties — modifica el valor en el editor

Fondo: var(--primary)
Edita --primary en el código →
CSS 
.s14-card {
  background: var(--primary, #4af);
  border-radius: 8px;
  color: #fff;
  padding: 14px 20px;
}
Tip: Usar @property para variables tipadas animables. Preferir variables para temas y evitar valores mágicos repetidos.
